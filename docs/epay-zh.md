# 彩虹易支付

支持传统 V1 接口：商户号 **PID** + 商户密钥 **KEY**，使用 MD5 签名。

## 1. 添加支付方式

进入后台 **财务管理 → 支付网关 → 创建**，名称填写“彩虹易支付”，网关选择“彩虹易支付”。

- **易支付网关地址**：填写商户平台提供的接口根地址，例如 `https://pay.example.com`，不要加 `/submit.php`。
- **商户号 PID / 商户密钥 KEY**：填写商户后台提供的凭据。密钥使用项目现有的加密设置存储。
- **支付方式**：留空进入易支付收银台，也可以指定支付宝、微信支付或 QQ 钱包。实际可用渠道取决于商户平台。

保存后，人民币账单的付款弹窗中即可选择此支付方式。新安装默认使用 **CNY（人民币，¥）**，在产品的计费方案中填写人民币售价即可，余额充值和续费也沿用对应币种。其他币种的账单不会显示此网关。

已有站点更新时，数据库迁移会补齐人民币，并将旧的美元默认值改为 CNY。旧产品的美元售价、已有账单、服务及余额保留原币种，不会按 1:1 换成人民币。请在产品各个计费方案和付费配置项中补充 CNY 售价；已有美元服务的续费仍按原币种计费，需核对并调整该服务的币种和续费金额后，才能使用人民币续费。其他有意设置的默认币种不会被覆盖。

## 2. 检查回调

确保站点网址填写正确，公网可访问，并使用 HTTPS。异步通知地址由系统自动填写：

```text
https://你的域名/extensions/epay/notify
```

此地址接收 V1 的 GET 通知。不要给它添加登录验证、人机验证或会改写请求参数的规则。

支付后会返回原账单页；只有通过签名、商户号、订单及金额校验的异步通知才会入账。重复通知不会重复记账。

## 3. 首次收款前验证

使用自己的商户配置创建一笔小额 **CNY 测试账单**，完成支付后检查账单是否已付款、交易流水是否只有一条，并核对平台订单号。自动化测试不能替代商户平台的实际收款验证。

如果用户打开收银台后，账单又被取消、调整金额或用余额支付了一部分，旧订单回调会被拒绝。请先核对商户平台的实际收款，再人工处理退款或对账，避免重复收款。

此版本不提供自动退款和免密续费；退款需在易支付商户后台处理后，在 Paymenter 中核对记录。
